보유 자격증

소개

요구사항을 화면 설계, API, 데이터 모델까지 한 흐름으로 이해하고, 혼자서도 기능 하나를 처음부터 끝까지 완성할 수 있는 개발자입니다.

Vue.js, React, jQuery로 사용자 친화적인 화면과 인터랙션을 만들고, Java·Spring·MyBatis로 서버와 API를 개발합니다. PostgreSQL, Oracle, MySQL 환경에서 데이터를 설계하고 다뤄 왔으며, 파일 업로드·스케줄링·보고서 출력·외부 서비스 연동 등 실무에서 자주 필요한 기능을 다양하게 구현했습니다.

지도·3D 기반의 복잡한 공공 서비스를 다루며 쌓은 경험 덕분에, 낯선 도메인도 빠르게 파악하고 개발에 적용하는 데 자신 있습니다.

엔드투엔드 개발

프론트엔드, 백엔드, DB를 모두 다뤄 기능 단위로 끝까지 책임지고 완성합니다.

성능 문제 해결

대용량 데이터를 처리하는 서비스에서 병목 구간을 찾아 개선한 경험이 있습니다.

읽히는 코드와 소통

일관된 스타일과 주석으로 팀원이 이해하기 쉬운 코드를 쓰고, 막히는 문제는 빠르게 공유합니다.
